# Linfoot Homes — immersive website concept

An independent redesign concept for portfolio/pitching purposes. It is **not commissioned by or affiliated with Linfoot Homes**.

## Preview
GitHub Pages: https://willoughbyorchard-cpu.github.io/linfoot-homes-concept/

## Pages
- `index.html` — home page with sticky scroll-driven room journey
- `homes.html` — country, conversion and city concept categories
- `approach.html` — design principles and the immersive interaction
- `contact.html` — public contact details linked to the official site
- `styles.css` — responsive styling and scene transitions
- `script.js` — mobile navigation, reveal animations and scroll-driven scene changes
- `assets/` — locally bundled illustrative Unsplash photography

## The scroll effect
The home page pins a full-screen scene while the user scrolls through four markers. The background zooms/pans and cross-fades from a hallway to living space, kitchen and exterior; the story text, chapter number and progress bar update as each marker crosses the viewport. Reduced-motion preferences are respected.

## Preview locally
Download or clone the repo and open its folder in VS Code. Use Live Server, or open `index.html` in a browser. All pages use relative links and images stored in `assets/`.

## Before any commercial use
The photography is illustrative stock imagery, not verified Linfoot Homes property photography. Replace it with approved/licensed project images, and have the company verify all details and copy before any official launch. The concept categories are not current property listings.
